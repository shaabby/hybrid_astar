# Map Demo

`grid_demo.html` is a self-contained HTML Canvas demo for the occupancy grid map.

Open it directly in a browser:

```text
map/grid_demo.html
```

It currently draws:

- a 60 x 36 square grid;
- rectangular obstacles;
- start and goal poses with heading arrows.

This file is a visual prototype for the later C++ generated `output/demo.html`.
